# Наследие ФПМИ

Заготовка Telegram-бота проекта «Наследие». Репозиторий: `IT-FAMCS/legacy-tg`.

При запуске бот задаёт имя **Наследие ФПМИ** и кнопку меню **Открыть Наследие**,
которая открывает **https://famcs-legacy.by** внутри Telegram как Mini App.
Используется существующий веб-интерфейс и его вход по логину и паролю.
Автоматическая авторизация через Telegram и привязка аккаунтов пока не реализованы.

Прикладных команд, обработки сообщений, рассылок, БД и обращения к API «Наследия» нет.
Бот не читает обновления и не меняет webhook. Это основа для будущей интеграции.

## Запуск

Нужен Python 3.13+; сторонних зависимостей нет.
Создайте бота через @BotFather, затем задайте `BOT_TOKEN` в окружении процесса.
`WEBAPP_URL` необязателен, по умолчанию `https://famcs-legacy.by`.

```bash
python bot.py
```

Для Docker скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` и выполните:

```bash
docker compose up -d --build
docker compose logs -f bot
```

Сам Python `.env` не читает; его передаёт Docker Compose.
Кнопка доступна в личном чате с ботом. `/start` пока не отвечает сообщением.
Если бота ещё нет, его создание и выбор уникального username делаются в @BotFather.
Отображаемое имя устанавливается автоматически при запуске.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m py_compile bot.py
```

`GET /healthz` на внутреннем порту 8080 отвечает после успешной настройки Telegram.
Это проверка процесса и выполненного запуска, а не непрерывная проверка Telegram/сайта.
При ошибке конфигурации процесс завершается с кодом 1; Docker перезапускает его.
Токен не включается в диагностические сообщения.

## Деплой

[Инструкция](DEPLOY.md): GitHub Actions проверяет код, собирает Docker-образ и публикует
`ghcr.io/it-famcs/legacy-tg:latest` и тег SHA. На сервере требуется один раз добавить
контейнер; после этого обновления может забирать существующий watchtower.
Токен нужен только на сервере, его не требуется добавлять в GitHub Actions.

Mini App использует существующий сайт напрямую; отдельный фронтенд и копия сайта не нужны.
Доступ к аккаунту определяется сервером «Наследия», а не Telegram user ID.
Для автоматического входа в будущем потребуются серверная проверка `initData`
и явная привязка Telegram к учётной записи.

Документация Telegram: [Mini Apps](https://core.telegram.org/bots/webapps),
[кнопка меню](https://core.telegram.org/bots/api#setchatmenubutton).
